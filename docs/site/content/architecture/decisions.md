Decisions that are expensive to reverse are ADRs, one file each in [`docs/human/decisions/`](https://github.com/Undefined6799/unset/tree/main/docs/human/decisions). Accepted records stay as written. The files are not rendered on this site.

Each ADR records its own status, acceptance and supersession in front matter ([ADR 0083](https://github.com/Undefined6799/unset/blob/main/docs/human/decisions/0083-each-adr-is-its-own-record.md)), so this table is built from the files each time the site is built; `npm run adr:index` prints the same table. The folder's [README](https://github.com/Undefined6799/unset/blob/main/docs/human/decisions/README.md) explains the format.
