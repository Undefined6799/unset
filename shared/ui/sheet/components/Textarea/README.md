# Textarea

A multi-line field styled exactly like Input: 1px `line-strong` border, `radius-xs` corners, `mono` 14px, label above, hint or `[err]` below.

## Provide

- `label`, `hint`, `error`, `rows` (default 4) and any native textarea props.

## Use

- Resizes vertically only; minimum 96px tall.
- Same states as Input: `ink-muted` border on hover, 2px `focus` outline, `danger` border with `[err] …` on error.
