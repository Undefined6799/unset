# Kbd

A keyboard key: `mono` 12px in a 24px box with a 1px `line-strong` border, a 2px bottom edge and `radius-xs` corners.

## Provide

- `children`: one key, `K`, `⌘`, `⇧`, `⏎`, `Esc`.

## Use

- One Kbd per key; put combinations side by side with a 6px gap and no plus sign.
- Use the Unicode symbol for modifier keys (⌘ ⇧ ⌥ ⏎).
