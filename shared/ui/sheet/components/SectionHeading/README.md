# SectionHeading

A numbered section title: the index in `mono` `ink-muted` followed by an em dash, then the title in `heading-2`, over a 1px `line` rule.

## Provide

- `title`: the section name, sentence case.
- `index` (optional): a two-digit string, `"01"`; the component adds " —".

## Use

- Number sections in order down a page; restart at `01` per page.
- `space-12` above a section heading, `space-6` below it.
