# Mark

The unset.sh mark, three fisheyes, drawn from the source file's exact geometry and filled with `currentColor` (`ink` by default: Platinum on Onyx, Onyx on Platinum), matching `unset-mark-platinum.svg` and `unset-mark-onyx.svg`.

## Provide

- `width` in px (default 72); the height follows the 828:220 ratio.
- `title` (optional): accessible name, default "unset.sh".

## Use

- Keep `mark-gap` clear on every side; never recolour it with an accent, stretch, or split the three units.
- In code, prefer this component over re-drawing; in files and print, use the SVGs in Logos.
