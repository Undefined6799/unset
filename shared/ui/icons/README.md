# Icons

The 36 icons on the design sheet's Icon list (`sheet/components/Icon/README.md`, approved by Alex 2026-10-03 18:02Z),
drawn by **Iconoir 7.12.1**, regular set, MIT licence (`LICENSE-iconoir.txt`, © 2021 Luca Burgio). Decision 33.

- `svg/<our-name>.svg.txt` are Iconoir's own `icons/regular/<iconoir-name>.svg` files at tag `v7.12.1`, copied byte
  for byte once, by hand, from `https://raw.githubusercontent.com/iconoir-icons/iconoir/v7.12.1/icons/regular/`.
  The `.txt` suffix keeps lint tools off copied third-party data. Nothing is fetched at build, test or run time, and
  no icon package is installed.
- `icons.json` is generated by `node scripts/ui/icons.ts` (never hand-edited). It records the Iconoir version, the
  sheet version, each icon's Iconoir name and sha256, and the drawings the `Icon` component renders inline. The run
  checks that the sheet's README and bundle are the bytes `sheet/source.json` recorded, reads the sheet's `ICONS`
  data as a plain literal without running the bundle, refuses any element or attribute outside the allowlist, and
  fails unless every file equals its sheet drawing. `shared/ui/scripts/icons.test.ts` checks `icons.json` is current.
- Adding an icon means adding it to the sheet first, with Alex's approval, then copying the file at the pinned tag.
